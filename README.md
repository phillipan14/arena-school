# Arena School brand assets

Official Arena School logo kit: seal, wordmark, patterns, and social-media sizes.
This branch is storage only. It is not part of the website and never deploys to Vercel
(`vercel.json` here turns deployments off for this branch).

**Download everything:** Code → Download ZIP on this branch, or
https://github.com/phillipan14/arena-school/archive/refs/heads/brand-assets.zip

The same files are in the shared Google Drive: Arena AI → 04 Marketing, Brand & Media → Logos → 01 Arena School.

## Naming
`arena-<seal|wordmark>-<logo color>-<on-background | transparent>[-size].png`
Files without a size suffix are full resolution; `-1024` / `-3000` are resized copies.
